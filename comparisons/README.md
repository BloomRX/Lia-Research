# Comparações — como ler esta pasta

Comparação só entra aqui quando existe uma **pergunta de decisão** e pelo menos dois
objetos já pesquisados com evidência. Comparar por comparar produz tabela bonita e
conclusão falsa.

| Comparação | Arquivo | Pergunta |
|---|---|---|
| Licença por projeto | `LICENSE-MODEL-COMPARISON.md` | como o ecossistema deve expressar licença por projeto |
| Servidor MCP | `MCP-SERVER-COMPARISON.md` | qual servidor de casa usar, se algum |
| Benchmark reproduzível | `BENCHMARK-APPROACH-COMPARISON.md` | como medir modelo sem virar fé |

## Critérios de honestidade (valem para todas)

1. Não comparar README com código: um lado pode estar `REPORTED` e o outro `CONFIRMED`
   — e isso precisa aparecer na tabela.
2. "Sem dados" é uma célula válida. Nunca preencher com estimativa não marcada.
3. Comparação não elege vencedor por número de estrelas.
4. Se os dois objetos não são comparáveis, o documento diz isso e termina.
