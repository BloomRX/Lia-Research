## O que continua **não** aceito

Nenhuma decisão de **implementação** foi aceita nesta base, e isso é intencional: a ordem
de serviço proíbe promover recomendação de pesquisa a decisão de implementação. Um
`ACCEPTED/` cheio de "adotar tecnologia X" significaria que a pesquisa autorizou mudança
de arquitetura — o que não aconteceu.

Quando o responsável de um projeto decidir implementar algo pesquisado aqui, o registro
entra nesta pasta usando `templates/decision-record.md`, com dono, data, escopo e gates.
