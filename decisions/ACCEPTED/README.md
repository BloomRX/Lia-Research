# ACCEPTED — vazio por decisão

Nenhuma decisão de implementação foi aceita nesta fundação, e isso é intencional.

A ordem de serviço de 2026-11-17 proíbe promover recomendação de pesquisa a decisão de
implementação. Nenhum diretório `ACCEPTED/` com conteúdo significaria que a pesquisa
autorizou mudança de arquitetura — o que não aconteceu.

Quando o responsável de um projeto decidir implementar algo pesquisado aqui, o registro
entra nesta pasta usando `templates/decision-record.md`, com dono, data, escopo e gates.
